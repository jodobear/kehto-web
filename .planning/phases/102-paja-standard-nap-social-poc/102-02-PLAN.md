## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Signer identity to Paja cache | Mutable account selection crosses asynchronous contact-list and profile warm operations. |
| Untrusted relay event to follow set | Kind-3 tags influence which profile authors Paja reads. |
| Paja cache to standard outbox service | Private stored values are merged into a napplet-visible normal result. |
| Paja host to sandboxed iframe | The iframe receives service envelopes but must not receive host relay, signer, or cache authority. |
