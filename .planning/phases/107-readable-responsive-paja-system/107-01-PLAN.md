Existing contracts to preserve:
- `navigateFrame(frame, config, generation, adapter, resolvedTarget?, windowId?, isCurrent?, onRegistered?) -> Promise<string | null>` in `browser-target-frame.ts` owns fetch/verified bytes, registration, CSP/prelude injection, and srcdoc.

New private contracts created here:
- `PajaTargetSurfacePhase = 'empty' | 'loading' | 'ready' | 'error'`.
- `PajaTargetSurface` exposes `showEmpty()`, `showLoading('initial' | 'retry')`, `showReady({ focusFrame })`, `showError(error, { focusRetry })`, and `destroy()`; it owns presentation/focus only.
- `createPajaTargetSurface(options)` receives a host container, existing iframe, return label, retry/return callbacks, and lifecycle-status callback. It is imported directly by browser host modules and is not re-exported from `packages/paja/src/index.ts`.
</interfaces>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Untrusted target/diagnostic -> Paja host DOM | Failure data crosses from fetch/verification errors into privileged host presentation. |
| Host recovery control -> verified loader | Local user action can replace the active iframe/session. |
| Sandboxed iframe -> host bridge | Only the registered current iframe source may establish readiness or send NAP traffic. |
