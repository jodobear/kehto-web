<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Pointer text -> resolver/verified artifact | Untrusted pointer selects Relay/Blossom content that must pass existing verification. |
| Runtime tab iframe -> host session | Ready/messages cross only from the registered current iframe source. |
| Host tab/retry controls -> lifecycle state | Local interactions can replace/close current sessions and must be single-flight/current-generation. |

## STRIDE Threat Register — ASVS L1

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-107-02-01 | Spoofing | Pointer/tab ready settlement | high | mitigate | Preserve signature/hash verification, origin/window registration, tab generation, current frame source, and current window ID before ready. |
| T-107-02-02 | Tampering | Retry loader selection | high | mitigate | Delegate only to `state.loadPointer(pointer)` or `reloadActiveRuntimeTab()`; conformance/source guards reject alternate traffic. |
| T-107-02-03 | Elevation of Privilege | Verified-byte iframe | high | mitigate | Keep CSP-before-bootstrap, signed bytes through srcdoc, injected bootstrap outside signed bytes, and sandbox without same-origin. |
| T-107-02-04 | Denial of Service | Rapid pointer/tab activation | medium | mitigate | Controller request generation plus disabled current action and existing per-tab generation rejection prevent duplicate work/sessions. |
| T-107-02-05 | Repudiation | Active-target presentation | low | accept | Development-only UI synchronizes visible/title/accessibility context; persistent audit is outside this visual phase. |
</threat_model>
