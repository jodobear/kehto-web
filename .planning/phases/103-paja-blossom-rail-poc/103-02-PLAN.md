<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Paja signer → Blossom authorization header | A host-signed bearer-like event crosses to a remote server. |
| uploader callback → generic upload service | Untrusted async timing can attempt duplicate or late state transitions. |
| napplet → runtime ACL dispatcher | A sandboxed caller requests upload or resource authority. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan | Verification | Residual risk |
|---|---|---|---|---|---|---|---|

| T-103-06 | Tampering | upload lifecycle | high | mitigate | One service-owned uploading state, one terminal state, live-entry gate, and teardown callback suppress stale output. | Deferred resolve and cross-window unit tests. | A remote durable write can already exist before cancellation; Plan 03 reports it only to the host. |
